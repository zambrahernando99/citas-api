# Workflow operativo

## INGEST

Leer fuente aprobada, sintetizar solo conocimiento durable en páginas existentes, enlazarlo, actualizar `wiki/index.md` y anexar una entrada en `wiki/log.md`.

## QUERY

Leer primero `wiki/index.md`, luego las páginas relevantes y verificar contra especificación o código. Separar evidencia de inferencia en la respuesta.

## LEARN

Tras una interacción sustancial, persistir únicamente HECHOS verificados, DECISIONES aprobadas, PREFERENCIAS explícitas o PREGUNTAS ABIERTAS relevantes. No guardar conversación literal.

## LINT

Revisar contradicciones, duplicados, páginas huérfanas, enlaces rotos, decisiones sin aprobación, hechos obsoletos y contenido sensible. Registrar el resultado en `wiki/log.md`.
