# Convenciones

- Cada afirmación durable se etiqueta como **HECHO**, **DECISIÓN**, **PREFERENCIA** o **PREGUNTA ABIERTA**.
- Un HECHO incluye fuente y se verifica contra especificación o código vigente.
- Una DECISIÓN indica quién la aprobó, fecha y consecuencias. Sin aprobación, es PREGUNTA ABIERTA.
- Los contratos REST tienen enlace a HU, implementación API y consumidor web cuando existan.
- No guardar secretos, tokens, passwords, credenciales, PII ni transcripciones de conversaciones.
- Mantener enlaces relativos válidos y actualizar el índice al crear o mover páginas.
