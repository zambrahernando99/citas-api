# Contratos REST

## HECHOS

- La API es REST/JSON directa entre `citas-web` y `citas-api`; el contrato se diseñará y documentará durante el proyecto. Fuente: PRD RF-20.
- Debe cubrir, como mínimo, autenticación, perfil/afiliación, catálogos, profesionales, disponibilidad, citas, reprogramaciones, agendas y bandeja ADMIN según las HU aprobadas. Fuente: PRD RF-01 a RF-20.

## PREGUNTAS ABIERTAS

- Versionado base, convención de recursos, paginación y formato estándar de errores.
- Formato/zona horaria de fechas, idempotencia de comandos y compatibilidad de cambios.
- Payloads y autenticación de endpoints destinados a n8n.

No se publican endpoints hasta enlazarlos con HU, pruebas API y consumidor frontend.
